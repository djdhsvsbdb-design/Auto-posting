# About AutoComment

**AutoComment** is a Geode mod for Geometry Dash Android 2.2081.

## What it does

- Stores a target level ID and a comment template in the mod settings.
- Offers a configurable automatic posting interval with a 5-minute minimum.
- Lets the player enable or disable automatic posting.
- Validates the level ID and rejects blank comment text.

## Compatibility

- Target game: Geometry Dash Android 2.2081
- Geode metadata: v5.11.2

## Important limitations

This repository is a development project. A successful Android build and an on-device test have not yet been confirmed. Automatic posting depends on the game's own networking behavior and server response. Android may suspend Geometry Dash when the app is backgrounded; this mod cannot guarantee execution while the operating system has suspended the game.

Use the feature responsibly and follow Geometry Dash's community rules.
